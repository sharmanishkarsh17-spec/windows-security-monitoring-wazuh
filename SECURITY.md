# Security Policy

## Scope

This repository contains configuration examples, Sigma detection rules, validation documentation, and supporting material for a Windows security monitoring lab project.

## Reporting Security Issues

If you identify a security issue in the repository, please report it privately to the project maintainer before publicly disclosing the issue.

When reporting an issue, include:

- A clear description of the issue
- Steps required to reproduce it
- The affected file or component
- Any relevant security impact

## Sensitive Information

Do not submit passwords, API keys, private keys, certificates, Filebeat keystores, raw security logs, OpenSearch databases, or other sensitive environment-specific information to this repository.

The repository is designed to use sanitized configuration examples and controlled validation evidence.

## Safe Testing

Testing should be performed only in environments where the tester has authorization.

Do not use the project configurations or detection tests to perform unauthorized credential access, destructive activity, or attacks against systems without permission.

## Disclosure

Security issues should be handled responsibly and disclosed only after an appropriate remediation or coordination process.
